# 研究文章

整理 GEO / AEO / AI Search 领域有研究价值的文章，优先收录原创研究、可复现分析、方法总结与有明确数据口径的案例。

## 收录范围

- 实证与数据：引用行为、信源生态、内容吸收与品牌可见性分析。
- 方法与实践：实验设计、测量方法、内容优化与案例复盘。
- 综述与观察：有清晰引用、证据或研究方法支持的领域综述和深度分析。

## 添加资料

1. 记录原文标题、作者或机构、发布日期与原文链接。日期未知时注明“未标注”。
2. 阅读笔记建议包含：研究问题、数据与方法、主要发现、适用范围和限制。
3. 文件名建议使用 `YYYY-MM-DD_作者或机构_简短标题.md`。日期未知时以 `日期未标注` 开头。
4. 在上方索引补充一行。保存全文、PDF 或截图前核对转载许可；授权不明确时保留原文链接和自己的阅读笔记。

引用时注明出处，区分原文结论、作者观点与本仓库的分析。第三方材料维持各自的原始许可。
