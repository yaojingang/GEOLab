## 下载与校验

单份资料可通过上表进入 GitHub 文件页并下载。大于 50 MiB 的 4 份文件使用 [Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage) 保存；通过 Git 获取全部资料时，请先安装 Git LFS，再执行：

```bash
git lfs install
git clone https://github.com/yaojingang/GEOLab.git
cd GEOLab
git lfs pull --include="06-conferences/*"
```

[sources.json](./sources.json) 记录来源、原文件名、顺序、字节数与 SHA-256；[SHA256SUMS](./SHA256SUMS) 用于核对完整文件。在本目录执行：

```bash
shasum -a 256 -c SHA256SUMS
```
