1. 核对原始发布页，记录标题、发布机构、发布日期、版本与来源链接。日期未知时注明“未标注”。
2. 确认允许转载后保存原文件；授权不明确时，保留原始来源链接和自己的阅读笔记。
3. 文件名建议使用 `YYYY-MM-DD_发布机构_简短标题.pdf`；阅读笔记使用同名 `.md` 文件。日期未知时以 `日期未标注` 开头。
4. 在上方索引补充一行，使用相对路径链接本地文件，并在笔记中区分原文结论与自己的判断。
