# 白皮书

整理 GEO / AEO / AI Search 相关的行业白皮书、平台指南与方法评测报告。优先收录发布机构明确、来源可核查、研究范围与方法清楚的资料。

## 收录范围

- 行业与生态：行业研究、市场观察、用户行为与应用趋势。
- 平台与产品：官方平台指南、产品研究及技术白皮书。
- 方法与评测：可见性测量、引用分析、评测框架与基准报告。

## 添加资料

1. 核对原始发布页，记录标题、发布机构、发布日期、版本与来源链接。日期未知时注明“未标注”。
2. 确认允许转载后保存原文件；授权不明确时，保留原始来源链接和自己的阅读笔记。
3. 文件名建议使用 `YYYY-MM-DD_发布机构_简短标题.pdf`；阅读笔记使用同名 `.md` 文件。日期未知时以 `日期未标注` 开头。
4. 在上方索引补充一行，使用相对路径链接本地文件，并在笔记中区分原文结论与自己的判断。

第三方资料保留原作者、机构与许可信息。仓库的内容许可适用于本仓库拥有权利的原创整理内容。
