证据被边界切成两半时，检索器只找回一半

命中块给数值，表头与注释却在邻块里（示意）§2 Problem Statement · PDF p.1
场景取自论文 §2 的失效模式：财务表的表头与数据行被分到两个块。先看常见做法丢了什么，再看 SCAR 如何逐块评估邻块。

先分清三个角色：种子块、邻块与扩展闸门

闸门是相对阈值：邻块得分超过种子相关性的 0.8 倍§4 · Eq.3 · PDF p.2
三个概念撑起全篇：边界碎片化是问题，扩展闸门是机制，结构连续性是惩罚项。切到专业模式可以看到三条公式的原始形式。

邻块过闸才扩展：门槛是种子相关性的 0.8 倍

λ=0.1、γ=0.80 全语料固定，半径 r ∈ {1, 2}§4–5.4 · PDF p.2
步进器走三步：检索种子块、计算邻块得分、过闸扩展。注意第二步的连续性惩罚，它把相邻与连贯区分开。

干预发生在检索之后、生成之前

训练自由、单次决策，可与任何分块策略组合§3–4 · PDF p.1–2
流程图定位干预环节：SCAR 不改分块器，改的是检索后的上下文组装。它属于检索时方案，与索引时分块方法互补。

召回与块量要一起读，单看哪个都会误判

块效率 = 召回 ÷ 平均块数：SCAR 0.118 对窗口 0.095§5.2 · Table 3 · PDF p.2–3
召回衡量证据找全没有，块数衡量上下文开销。只看召回会选静态窗口，只看块数会选 Top-5，两个一起读才能看清取舍。

复验先钉住：同金标、同分块器、同检索参数

门槛随种子相关性浮动：弱命中降低门槛

λ=0 时严格尺度不变；小 λ 只引入轻微尺度修正§4.2 · PDF p.2
方法拆解强调两个设计性质：尺度稳健让参数跨模型迁移；自适应门槛在检索器不确定时放低门槛。专业层给出三条公式。

调 γ 阈值：邻块选择在收益与代价之间移动

默认 γ=0.80：表头块过闸，薄注释块被挡（示意）机制据 §4 · 示意数值 · 论文数字见 Table 2
招牌实验：先切换三种策略，再拖动 γ。默认 0.80 时薄注释块被闸门挡住，这正是论文自述的失效模式；把 γ 降到 0.79 就能找回它。

省 22.9% 块量，付 3.9 个百分点召回

块量差 d=−1.49（大效应），召回差 d=−0.33（小效应）Table 2 · Table 3 · §6.4 · PDF p.3–4
可比较的数字画成条形图，基线是静态窗口。三个视图：按方法、按语料、按下游生成。专业层附配对检验与消融数字。

边界碎片化：一半证据在命中块，另一半在邻块

证据 E = {c_i, c_{i+1}}，检索器只命中 c_i§2 · PDF p.1
第一条发现定义问题：递归分块在句子或条款中间切开证据，论文举的例子是表头与数据行分离、法律定义前后半句分离。

静态窗口全收邻块，无关内容推高 token 开销

窗口 ±1 平均 10.16 块，父检索 50.2 块Table 3 · §6.7 · PDF p.3–4
第二条发现给问题定价：无条件扩展把无关邻块也带进上下文。10-K 上窗口平均 1,281 token，SCAR 只用 934。

相对阈值免校准：同一组参数跨三种嵌入模型

BGE 降块 12.7%、zembed-1 降 17.2%，召回 0.913 与 0.956§6.4 · PDF p.4
第三条发现解释设计：门槛与种子相关性成比例，嵌入模型的相似度尺度变化被抵消，因此同一组参数能迁移。

块量收益是大效应，召回代价小而真实

召回差 95% CI [−0.058, −0.022]，Wilcoxon p=0.011§6.4 · PDF p.4
第四条发现是统计口径：块量节省 d=−1.49 是大效应；召回代价 d=−0.33 小但显著。省多少、丢多少，两个都要报。

对照 SproutRAG：检索时扩块与索引时建树
