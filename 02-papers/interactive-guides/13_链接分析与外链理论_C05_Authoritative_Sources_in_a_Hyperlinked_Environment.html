枢纽与权威相互强化

好枢纽指向好权威、好权威被好枢纽指向，交替迭代收敛到主特征向量摘要 · PDF p.1
开场给结论：HITS 同时找两类页面——权威页与枢纽页，用相互指向的关系打破循环定义。封面右侧四个数字后面都会展开。请学员记住一句话：权威是被枢纽投出来的。

沿着问题与证据完成这门课

先读结论，再拆原理、指标、方法、发现和应用摘要 · PDF p.1
过一遍四个学习问题与七章路线。术语按钮先点一遍：权威页、枢纽页是全课的两个核心词。提示学员：第 10 页的迭代演示是本课主菜。

宽泛主题下如何从链接结构找出权威页面

只按入链数挑页面，java 查询会混入度假广告与 Amazon 首页§3 · PDF p.7
对比两种做法。常见做法在论文 java 实验里现了原形：入度最高的页面混着度假广告页。切换「研究启发」看 HITS 思路：让枢纽与权威互推。

权威页与枢纽页：一对互相成就的页面

枢纽页串起同主题权威，价值由指向质量决定§3 图 2 · PDF p.7-8
逐个点开三张概念卡。右侧结构图按论文图 2 重绘：无关的泛流行页入链再多，也进不了枢纽—权威的稠密结构。专业层有矩阵记法。

方法沿着这些环节产生作用

前 200 做根集 → 扩成 1000-5000 页基集 → 交替更新收敛§2-§3 · PDF p.5-10
步进三步：取根集、扩基集删站内链、迭代收敛。下方参数卡给出 t=200、d=50、k≈20，复现时逐项固定。根集内部几乎没有链接结构，这是扩邻域的理由。

明确干预环节才能解释效果

只适用于结果丰富的宽泛主题；窄主题会扩散到相邻宽主题§2 p.6 · §7 p.24
两个前提：删站内导航链接，否则站点结构污染分数；主题要宽，否则迭代被更宽的主题赢走。第 16 页展开扩散现象。

权威分靠枢纽分定义，枢纽分靠权威分定义

两类分数互为定义，归一化后只比相对份额§3 · PDF p.8-11
切换两种分数：权威分是入链枢纽分之和，枢纽分是出链权威分之和。专业层给矩阵形式，并列出与 PageRank 的公式差异。

实验设置限定结论的适用范围

根集取 AltaVista 前 200，基集 1000-5000 页，删站内链接后迭代§2 · PDF p.5-6
理论框架的证据是推导加真实查询实验。右侧四段原文节选可切换：摘要、构图、迭代定理、Clever 评测。逐段核对口径。

保持对照一致才能解释变化

复现要固定 t、d、删链规则、迭代轮数与截断数 c§2-§3 参数 · PDF p.5-11
给复验者一张参数清单：查询与根集、扩展上限、迭代与截断、对照基线。勾满四项说明方案完整；勾选本身不证明因果识别。

点一次迭代，看枢纽分与权威分交替收敛

每次点击执行半步：I 更新权威分，O 更新枢纽分，循环至稳定§3 · PDF p.8-11
招牌演示：连点「执行下一步」看 I/O 交替。盯住灰色的 X：第 1 轮与权威并列，之后一路萎缩到 0。右下是与 PageRank 的三点差异。

java 查询：入度混入广告页，HITS 挤掉它们

入度排序混入度假广告页；HITS 权威分把同主题页面排成一线§3 · PDF p.7、11
左侧是论文实测：java 查询入度最高的一组页面；右侧是 HITS 前 5 权威与分数。并排比较，讨论差别从哪来：枢纽的共指结构。

数字需要连同口径一起读取

50/31/19 战绩分布与 java 权威分均为论文实测§8 p.26 · §3 p.11
五块读数：1369 条评分、战绩分布条形图、39800 稀疏度、java 权威得分、20 轮收敛。每个数字都带出处与口径，条形图按线性比例绘制。

权威页常不含查询词，文本排序难找到

权威需要外部信号：官网常不写主题词§1 · PDF p.2
Harvard 被上百万页面提及，文本排序却轮不到官网；搜索引擎官网甚至不含 search engines 字样。链接是把判断外包给写链接的人。

枢纽页把同主题权威页串成稠密结构

共指结构分辨主题统一性，泛流行页出局§3 · PDF p.7-11
java 例子的两面：入度排序混入广告页；HITS 靠枢纽共指分辨主题。可回第 10 页用演示重放这一过程。

非主特征向量能分出主题的多重含义

jaguar 的三种含义对应三个特征向量§6 · PDF p.22-23
jaguar 分出游戏机、NFL 球队、汽车三种含义；abortion 的正负两端分开对立立场。非主特征向量是主题消歧工具。

主题过窄时结果会扩散到更宽泛主题

WWW conferences 查询浮出的是一般 WWW 资源§7 · PDF p.24
AltaVista 只有约 300 个候选页，主题不够宽，迭代被更宽的主题赢走；补救办法是用非主特征向量找回会议页。

相关研究帮助检验迁移边界

PageRank 全库离线算一个通用分；HITS 按查询现算两类分§5 · PDF p.16-17
三组对照：本篇、PageRank、同仓库的后续改进。迁移比较先对齐对象、阶段与指标，数字不能直接相加。

把方法还原为一次具体操作

search engines 查询：五家引擎官网以权威分浮出§1 p.2 · §3 p.11-12
论文原例：五家引擎首页几乎不含查询词，HITS 把它们排进权威前五；Gates 例子的 roadahead.com 在 AltaVista 只排第 123。本页不估造收益。

不同角色需要不同的执行清单

三个角色各一份清单，每条建议都能追溯到发现页。共同底线：示意与推断要和论文实测分开。

成熟工作形态可以承接研究方法

资源清单、来源核验、参数卡是三种可承接形态本课推断 · 映射 §2-§3
把方法落进日常形态；对应关系是本课推断，先小范围试再推广。
