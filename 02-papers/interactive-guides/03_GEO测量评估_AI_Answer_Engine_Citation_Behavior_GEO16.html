GEO页面质量审计

关键数字：70 条行业提示 · 1,702 条引用 · 1,100 个 URL · 78%（有条件）摘要 · PDF p.1
这一页先给结论：GEO-16 用 16 个支柱给页面打分，在 B2B SaaS 样本里，质量分每高 1 个标准差，被引用几率约 4.2 倍。提醒学生两个易混点：题名说 16 个引擎，实际只采集了 3 个平台；78% 带着严格前置条件。

沿着问题与证据完成这门课

先记结论与条件，再拆计分口径，最后看跨引擎差异。摘要 · §4.1
路线按四个问题展开：关联多强、分数怎么算、引擎差多少、条件何时成立。每个问题都有对应页面与交互；学生可直接点章节跳转。

页面质量信号与跨引擎引用有什么关系

总分看不出支柱差异，审计要落到支柱与条件上。§4.1 · PDF p.4
左边是常见做法：只盯一个总分。右边是论文做法：按支柱审计、锁定工作点、同口径复测。让学生切换两种视角，说出总分掩盖了什么。

研究对象需要先拆开再比较

每支柱 0–3 档；G=Σb/48，H 统计档位≥2 的支柱数。§4.1 · PDF p.4
这一页把研究对象拆开：支柱、档位、G、H 四个量。切换三个环节，确认学生能区分“页面属性分”与“被引用次数”。

方法沿着这些环节产生作用

按支柱审计 → 计算归一化质量分 → 比较不同引擎引用。§4.1–4.4 · PDF p.4–5
三步走：先审计页面并打档位，再合成 G 与 H，最后跨引擎比较引用结果。专业层可展开采集与回归口径。

明确干预环节才能解释效果

论文测量的是关联；三个平台的采集范围决定可推断的边界。摘要 · PDF p.1
强调干预环节：研究没有改页面，只观察引用与分数的关系。能支持什么、不能支持什么，都从这一点推出。

指标分别回答不同的效果问题

G、H、引用率各答一个问题；先核对分母再读数。§4.1 · §5.2 · PDF p.4–6
三个指标切换查看。G 是页面属性，H 是支柱达标数，引用率是结果量。专业层给出公式与聚合口径，出处逐条可查。

实验设置限定结论的适用范围

70 条提示 × 3 平台；域名聚类标准误；按 Youden J 选阈值。§4.1–4.5 · PDF p.4–6
设计页是证据库：五段原文节选可切换。请学生找出样本量、引擎集合与阈值选择方法各在哪一段。

保持对照一致才能解释变化

复验四查：同一提示与引擎、口径一致、报告 CI、区分关联与因果。§4.5 · PDF p.5
让学生为自己的复验方案勾选四项。勾满说明基本要素齐了，但勾选本身不能证明因果识别成立。

方法的每一步都有独立作用

档位阈值固定；缺失字段按 δ_j 有界扣分。§4.1 §4.4 · PDF p.4–5
按三步拆方法，每步给一个检查点。第三步提醒：跨引擎比较要同时报告均值、CI 与引用率。

拨动支柱档位，看页面是否进入引用工作区

工作点：G≥0.70 且命中≥12，对应 78% 交叉引用率。摘要 · §5.4 · PDF p.1/6
本课招牌演示：16 个支柱按钮，点击循环 0–3 档。右侧实时计算 G 与 H 并对照两个阈值；只有同时越过阈值才亮出论文报告的 78%，其他区间论文没有给数。让学生体会条件的重要性。

数字需要连同口径一起读取

Table 2 与 Table 3 的数字连同口径一起读取。PDF p.6
四个视图：关键计数、引擎对照、支柱关联、原文表格。切换时提醒学生分母在变：引用条数、页面数、条件子样本。

元数据与时效信号关联较强

Metadata & Freshness 关联最强：r=0.68，引用影响 +47%。Table 3 · PDF p.6
第一条发现带最强系数。提醒：r 是合并样本的相关，+47% 是论文对相关的换算，分引擎的相关正文没有报告。

语义HTML和结构化数据值得审计

语义 HTML r=0.65、结构化数据 r=0.63，紧随元数据之后。Table 3 · PDF p.6
第二条发现关于结构。语义结构让解析更稳，但 schema 必须与可见内容一致，缺失字段会被扣分。

引擎引用页面的质量分布不同

三平台被引用页面均值 G：0.727 / 0.687 / 0.300。Table 2 · PDF p.6
第三条是反常发现：Perplexity 引用的页面质量分明显更低。统一阈值在不同引擎上含义不同，跨引擎前要先重新标定。

观察关联需要与因果效果分开

78% 有前置条件；OR=4.2 描述关联强度。摘要 · §5.4 · PDF p.1/6
第四条守边界：观察性设计没有操纵页面，改一个字段不会自动获得同等提升。引导学生在方案里写成待验证假设。

相关研究帮助检验迁移边界

与《脱离引擎的评分边界》对照：先对齐对象、阶段与指标。相关论文 · 摘要
相关研究检验迁移边界：离线分数更适合当质量过滤。对照时先对齐对象、阶段与指标，数字不能直接相加。

一次文档页改造命中三个强关联支柱

改动按支柱映射；示意案例，未在论文中实测收益。Table 3 · §4.4 · PDF p.6/5
用一份《数据迁移指南》做示意改造：补日期元数据、重排语义标题、加 JSON-LD 与来源段。四行对照各自命中支柱，最后回审计台把档位拨一遍。

不同角色需要不同的执行清单

行动为本课推断：先做小范围同口径对照，再谈推广。本课推断 · §6
三个角色三张清单。共同点：先固定口径，再复测，最后才谈收益。避免事项都指向同一个坑——把 78% 当承诺。

成熟工作形态可以承接研究方法

记分卡、看板、口径变更记录承接研究方法；映射为本课推断。本课推断
三种成熟形态：审计记分卡、引用监控看板、口径变更记录。它们分别承接审计、比较与复测三个环节。

结论的边界决定应用的尺度

观察性设计 + 单一时点 + 构念覆盖不全，先看清再迁移。§6 Threats to validity · PDF p.8
六条局限按影响排序。前两条高影响：因果未验证、样本范围。迁移到自己的项目前，至少核对前两条，并记住题名与采集范围的混淆。

带走结论时也要带走条件

每张卡片背面带依据与一个用法。Table 2/3 · §5.4
六张卡片可翻面。请学生先念正面结论，再翻面核对依据与用法，最后用复制按钮带走带出处的要点。
