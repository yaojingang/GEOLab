中文平台的引用与呈现

8 个界面 · 614 条受控查询 · 清洗后 160,860 条引用记录摘要 · PDF p.4
这门课讲一篇 2026 年的中文平台实证：4 个主流大模型平台、Web 与 App 共 8 个界面、614 条受控查询，每组合固定重复 3 次，清洗后得到 160,860 条引用级记录。右上四个数先混个眼熟：8.3% 是品牌从引用池进入答案的比例，12.4% 是联系方式贡献率。全课反复出现的一句话：先看分母，再谈数字。

沿着问题与证据完成这门课

沿四个问题读：跨界面差异、品牌筛选、实体溯源、指标口径研究问题 · PDF p.5
路线按四个问题组织：同一平台的 App 和 Web 给的来源一致吗？品牌进了引用池为什么九成进不了答案？哪些联系信息容易被带进答案？传统 SEO 分数能不能预测引用？右侧可跳章节，术语都挂了浮层。

合并 App 与 Web 的数据，排行会失真

同平台 App 与 Web 域级重叠 0.19–0.51，合并会抹掉主差异Table 4-1 · PDF p.37
先看一个常见错误：把 8 个界面的数据合并成一份排行。论文测了同平台两个界面的来源集合重叠：域级 Jaccard 最高 0.507，最低 0.190；通义在 URL 级只有 0.014。切换右侧看两种做法的差别。

研究对象需要先拆开再比较

四个构念各配单位：引用吸收、实体曝光、未匹配溯源、跨界面一致性Table 1-4 · PDF p.13
研究对象拆成四个构念：引用吸收（来源内容被用到什么程度）、实体曝光（品牌和联系方式是否进入答案）、未匹配溯源（答案实体能否回到同期来源）、跨界面一致性。点上面三个环节，看每个环节的数据单位。

方法沿着这些环节产生作用

分层采集 8 个界面 → 清洗成 160,860 条引用记录 → 分层建模§1.1 · PDF p.10
方法链条三步：分层采集（8 个界面 × 614 条查询 × 3 次固定重复）；字段关联与清洗（214,119 条原始记录变成 160,860 条引用级主表）；分层建模与跨界面比较。专业模式有每步检查点。

明确干预环节才能解释效果

观察性关联：无随机化，抓取覆盖与匹配误差限制溯源研究局限 · PDF p.44
这一页先说清干预环节：论文没有做单因素随机化，所有结论都是查询集与平台范围内的条件关联。左下与右下两个面板分别列「能支持什么」与「边界在哪」。

指标分别回答不同的效果问题

先问分母：品牌候选 632,256 个；联系方式另有分母Table 3-1 · PDF p.29
四个指标四个分母：品牌选择率的分母是 632,256 个候选；联系方式贡献率的分母是含联系信息的来源；Jaccard 的分母是并集；半衰期来自指数拟合。切换指标看通俗与专业两档口径。

实验设置限定结论的适用范围

每查询 × 界面固定重复 3 次；分析前按 run 取并集再配对§1.1/§4.1 · PDF p.10,37
研究设计是受控采集，不是平台日志。每查询 × 界面组合固定重复 3 次，分析前按 run 取并集。右侧切换 5 段原文节选：摘要、三态分类、深度模型、配对方法、结论。

保持对照一致才能解释变化

复验四件套：分层、并集、清洗口径、负向结果本课推断
给你的复验方案做检查：App 与 Web 是否分开？是否固定重复并先取并集？清洗口径是否留痕？未匹配与负向结果是否报告？勾满 4 项只是具备基本要素，不能自动证明因果识别成立。

方法的每一步都有独立作用

每一步留检查点：成对编码、清洗链路、三级 Jaccard§4.1 · PDF p.37
方法拆解配了 3 个检查点：界面代码成对登记（DB↔DOUBA 等）；清洗链路前后记录数留痕；Jaccard 分 URL、域、站名三级。点击切换。

同一平台换入口，来源集合对不上

四平台没有任何一对界面给出相同来源集合Table 4-1 · PDF p.37
招牌实验台：选一个平台，看同平台 App 与 Web 的来源集合重叠和答案形态。豆包域级 0.505，URL 级掉到 0.310；通义几乎不重叠，64.2% 的查询连一个共同 URL 都没有。答案长度与引用条数也按界面分叉，切换右边的两个维度。

数字需要连同口径一起读取

8.3% 与 12.4% 分母不同，不能相乘或直接比较§3.6 · PDF p.35
证据读数 4 个视图：两道总闸 8.3% 与 12.4%（分母不同不能互除）；品牌选择率梯度（虚线为 8.3% 基线）；联系方式检出与曝光的错位；时效半衰期。最后一个按钮是原文表格节选。

品牌进入引用池后仍会被筛选

632,256 个品牌候选只有 8.3% 进入答案Table 3-1 · PDF p.29
发现一：品牌进入引用池后仍被二次筛选。总体 8.3%，九成多被筛掉。梯度陡：1 条来源提到 2.1%，11 条以上 59.9%；深度引用 20.7%，名义引用 1.5%。看左下小图与基线。

跨源冗余与内容适配关联实体曝光

跨源冗余 SHAP 0.581，品牌选择的第一驱动Table 3-2 · PDF p.30
发现二：跨源冗余是品牌选择的第一驱动（SHAP 0.581），内容适配次之；联系方式曝光由查询子题主导，品牌类查询几率比约 89 倍。注意：预测重要性不等于因果。

时效需求对应不同日期分布与半衰期

高时效半衰期 39 天，低时效 68 天Table 2-5 · PDF p.26
发现三：时效分层。高时效引用页中位年龄 18 天，低时效 101 天；半衰期 39 天对 68 天。含义是更新节奏分层，不是所有内容都要追新。

部分答案实体无法回溯到可见引用正文

13.02% 品牌曝光、71.1% 联系信息回溯不到同期来源§3.3/§3.4.1 · PDF p.31,33
发现四：溯源缺口。13.02% 的品牌曝光与 71.1% 的联系信息匹配不到同期可见来源。论文提醒正文抽取排除了按钮、页脚与 JSON-LD，缺口里有测量定义的成分。

相关研究帮助检验迁移边界

平台维度极差 0.32，大于六个行业组间的 0.059Table 4-3 · PDF p.39
对照阅读：与《引用选择与内容吸收》对齐平台与指标后比较。本篇补一个维度：平台间差异（极差 0.32）大于行业组间差异（0.059），跨研究比较先分平台与界面。

把方法还原为一次具体操作

确定性查询最易集中引用；官方渠道信息最易被呈现§2.1.2/Table 3-4 · PDF p.21,33
案例是论文报告过的确定性查询：极米投影仪的官方售后电话。95.3% 的查询首域占比低于 30%，只有 0.8% 超过一半，售后、政务与定义类最集中。把答案里的电话与官网逐一回查来源：热线、官网、公众号的曝光份额高于正文检出。

不同角色需要不同的执行清单

行动建议为本课推断，需按界面分层设计对照本课推断
三个角色的清单都按界面分层：内容负责人优先测跨源覆盖；技术员留清洗链路与三级 Jaccard；审核员核对未匹配口径。避免项在左侧黄色框。

成熟工作形态可以承接研究方法

看板分界面、数据留链路、未匹配建台账本课推断
成熟形态三件：按界面分列的监测看板、引用级数据字典与清洗日志、未匹配实体溯源台账。映射是本课推断，先小范围复验再扩大。

结论的边界决定应用的尺度

无随机化；只见已入选页面；抽取排除结构化区域研究局限 · PDF p.44
6 条局限按影响分级：无随机化、只见已入选页面、抽取排除结构化区域是高影响；LLM 标注、相关对照、日期缺失是中影响。点击看每条约束什么。
