引用由什么驱动

158,099 条回答、468,037 条引用：检索曝光解释 32%，页面特征只有 2.8%Table 3 · PDF p.6
这门课讲一篇 2026 年的实证测量：两位多伦多大学的作者把 651 条宽带问题连续 90 天发给三个生成式引擎，再用一个 B2B 市场复验。先记住一对数字：引擎自己的检索解释 32% 的同站引用变异，页面特征只有 2.8%。接下来 22 页看这个对比是怎么测出来的。

沿着问题与证据完成这门课

四个问题：同站效应、解释力对比、查询改写、品牌先验摘要 · PDF p.1
课程按七章走。第二、三章建立同站比较的口径，第四章看方法与证据读数，第五章逐条过四个发现，第六章落到品牌名实验和行动清单，第七章讲边界与自测。右侧路线可以直接点。

补了推荐做法，页面仍可能不被引用

跨网站比较容易把网站声誉记到页面特征头上§1 · PDF p.1
从一个常见困惑开始：FAQ 块、结构化数据都补了，页面还是没有引用。论文的答案藏在比较方式里：这些做法集中在本身被引更多的网站上，跨网站比较会误导。右侧切换两种做法，看结论如何反转。

研究对象需要先拆开再比较

解释变异、检索曝光、同站效应：三个词撑起全篇§3.2–3.3 · PDF p.3
这一页拆三个概念。解释变异是模型对差异的解释比例，检索曝光指页面进入引擎自己的检索结果，同站效应强调只与同一网站的其他页面比较。点击步骤按钮，看每个环节在做什么。

方法沿着这些环节产生作用

同站比较 → API 重放检索 → 控制品牌与产品事实§3 · §6.6
方法分三步：先在同一网站内部比较页面；再通过 API 重放，看引擎每次实际改写了什么查询、检索回什么页面；最后用控制实验单独改品牌名与产品事实。每一步回答一个不同的问题。

明确干预环节才能解释效果

观察分析与控制实验识别不同的量，解释比例非因果贡献§3.3 · §8
强调研究位置：这篇论文观察生产环境。同站设计去掉了网站之间的差异，但同站页面间的未测量差异仍在；控制实验只在答案环节逐个改因素。两类证据要分开解读。

指标分别回答不同的效果问题

y = log₂(1+c)，按网站去均值；特征须过五项检验§3.3 · Table 2
指标页看口径。结果变量取 log₂(1+引用数)；回归按网站去均值，所以系数是同站比较的含义。14 项特征要同时通过五项稳健性检验才算数，这就是 FAQ 块们出局的原因。专业模式里有公式。

实验设置限定结论的适用范围

90 天 × 两个市场 × 三引擎；重放 13 次 / 11 天§3.1 · §6.1
设计页记三件事：消费市场 651 问、B2B 市场 55 问，各收集 90 天；重放把同样的问题经 API 发回 13 次。三引擎里只有 ChatGPT 和 Gemini 能重放，Perplexity 不行。

保持对照一致才能解释变化

复验清单：口径、基线、版本、负向变化缺一不可本课推断
这是给复验方案用的检查清单，勾满四项只说明方案完整，不等于因果识别成立。用的时候对照批判阅读页的局限清单一起看。

方法的每一步都有独立作用

同站去均值、五项检验、API 重放：各自守住一环§3.3 · §4.1 · §6.1
方法页把三个环节再拆细：同站比较靠去均值回归，页面特征靠五项检验筛洗，检索环节靠重放暴露。点按钮逐步看每一步在守住什么。

同站配对才能看清：检索决定引用

匹配查询的页面胜出，推荐做法失效，检索决定引用Table 2 · Table 3
招牌演示分三步。第一步看同一家网站的两类页面：带 FAQ 块的汇总页和标题即答案的页面；第二步看引擎为同一问题改写的检索词，以及按自排名次的被引率；第三步把 32% 对 2.8% 的解释力对比画出来。页面与检索词是示意，数字全部来自论文。

同口径对比 32% 对 2.8%；引擎差异看 Table 1Table 1 · Table 3
证据读数页。左边切换四个核心数字，选到 32% 或 2.8% 会画出同口径对比条形图；右边切换三个引擎的无引用率与平均引用页数。Perplexity 95.8% 的回答什么都不引用，是引擎差异最极端的例子。

跨站关联可能掩盖站点差异

跨网站 +18.1%，同站 −3.4%：辛普森悖论Table 2 · Figure 1 · PDF p.4–5
第一条发现是方法论警告。跨网站看，每条推荐做法都伴随更高引用；同站看，效应全部消失。原因是做法集中在高被引网站。切换三个视角，再看下方条形图的对比。

检索曝光比页面属性解释更多变化

检索曝光 32%，页面特征 2.8%，打乱后剩 0.05%Table 3 · PDF p.6
核心发现。重放让检索环节可见：ChatGPT 引用的页面全部来自自己的检索，自排第 1 位被引 43.8%。条形图把 32% 与 2.8% 画在同一口径上。记住解释比例与因果份额的区别。

引擎改写查询改变匹配入口

每次回答重写查询：加品牌 28%、加年份 23%、重叠 2.7%§6.3 · PDF p.6
第三条发现解释经典排名为什么帮不上忙：引擎每次回答都重新改写子查询，同日两次改写只有 2.7% 重叠，检索到的页面 97% 不在 Google 前 50。页面要匹配的是这些查询的语义。

品牌记忆能影响搜索和推荐

先验品牌 67% 写入查询；46% 品牌提及无支持页面§6.5 · PDF p.7
第四条发现关于模型记忆。品牌在先验里，就更可能被写进查询、更容易被引用，甚至不需要任何支持页面就被点名。B2B 市场里模型几乎不认识那些厂商，第三方页面的提及就变得关键。

SAGEO Arena 受控评估，与本篇观察口径互补相关论文摘要
对照阅读：本篇在生产环境观察检索环节，SAGEO Arena 在受控环境评估 GEO 方法，并显示改写可能损伤检索与重排。两者口径不同，数字不能直接相加。

把方法还原为一次具体操作

论文原例：相同事实，揭示品牌名重排产品排序§6.6 · Table 4 · PDF p.7
这是论文的控制实验原例：简介等长、事实相同，只动品牌名。Spectrum 被点名掉 33 分，Google Fiber 升 12 分，小众厂商 Loopio 升 16 分。名字带来的是模型对品牌的既有信念。

不同角色需要不同的执行清单

行动为本课推断：先同站测量，再看检索与匹配本课推断
三个角色各一份清单，共同点：先做同站测量，再保存真实改写查询，最后用对照实验验证。每条建议都能追溯到前面的发现。

成熟工作形态可以承接研究方法

把同站比较与重放放进报告与实验记录本课推断
成熟形态页给三个载体：带证据的说明文档、分层测量报告、可复现实验记录。对应关系是本课推断，先小范围试，再决定扩大。

结论的边界决定应用的尺度

关联与因果、测量窗口、引擎漂移：边界在此§8 Limitations
六条局限按影响排序。最重的两条：结果是关联，同站设计去不掉页间未测量差异；重放走 API，与消费端应用的行为未必一致。引擎持续变化，2026 年的测量要定期复验。
