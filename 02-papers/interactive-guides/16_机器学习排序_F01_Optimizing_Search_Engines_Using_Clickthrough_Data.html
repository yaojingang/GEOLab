用点击数据优化搜索引擎

把点击日志转成文档两两偏好，训练排序函数；仅用约 260 条带点击查询后，该组用户点击次数在 95% 显著性水平上超过 Google。摘要 · PDF p.1
先读封面的结论与四个数字：260 条训练查询、29 比 13 胜过 Google、112 条离线查询、约 10% 偏好错误率。提醒学生每个结论都带条件：约 20 人同质用户组、线性排序函数。

沿着问题与证据完成这门课

先读结论，再拆原理、指标、方法、发现和应用。课程结构
带学生过一遍四个入口问题，点开术语按钮预习偏好对与位置偏差。本课主线：点击怎么变成训练信号，又怎么变成一版更好的排序。

搜索引擎能否不靠人工标注，直接从点击日志学排序

把同一次搜索里点过与没点过的结果转成两两偏好，持续训练排序摘要 · PDF p.1
对比两种常见做法：专家标注贵在人工，点击量直接当分数错在位置偏差。切换到「研究启发」，看论文给出的第三条路：两两偏好对。

研究对象需要先拆开再比较

Kendall 相关：两个排序的一致程度，逆序对越多值越低§3 · PDF p.3
三个按钮对应方法三步，逐个点开讲。强调研究对象是文档两两之间的先后关系，每条训练信号都长成「A 应排在 B 前面」。

方法沿着这些环节产生作用

记录查询、排名与点击三元组 → 从点击提取文档对相对偏好 → 训练排序 SVM 得到权重§2.1 / §2.2 / §4 · PDF p.2–4
步进器按三步走：记日志、提偏好对、训练排序 SVM。指出论文的干预在第 2、3 步：数据采集照旧，改动在怎么用日志。专业模式有各步的细节与出处。

明确干预环节才能解释效果

结论来自约 20 人的同质用户组与线性排序函数；点击带位置偏差与噪声，重复点击能否操纵模型当时尚未解决。§5.3 / §7 · PDF p.7–9
用流程图高亮看干预环节。输入是自然产生的日志，输出是一版按这组用户偏好调过的排序函数；结论只覆盖这类同质小用户组。

指标分别回答不同的效果问题

τ=(P−Q)/(P+Q) 衡量两个排序的一致程度；在线比较用双尾二项符号检验§3 · PDF p.3 / Table 2 · PDF p.7
切换两个指标：Kendall τ 管离线一致性，排序 SVM 是训练方法。专业模式里有 τ 的公式和论文算例（τ=0.4），以及排序 SVM 的优化问题。

实验设置限定结论的适用范围

元搜索引擎 Striver 融合 Google 等五家引擎结果；离线实验 112 条查询，在线实验约 20 名用户、260 条训练查询。§5.1–5.3 · PDF p.5–7
Striver 融合五家引擎的候选，点击经代理服务器记录。证据选择器可切看原文节选：摘要、方法与评估、在线实验设置。

保持对照一致才能解释变化

点击只能当相对偏好使用，把点击率直接当质量分是误读，位置偏差要衔接后续点击模型课程。§2.2 · PDF p.2–3
四个复验检查项逐个勾选：对象、基线、版本、负向结果。提醒学生：勾满只说明方案要素齐了，因果识别仍要靠设计保证。

方法的每一步都有独立作用

每步都要检查：三元组有没有记全、偏好方向有没有提反、权重是否可解释§2.2 / §5.4 · PDF p.3, 8
三步各点开看对应的核对要点。第一步最容易被忽略：没有当时呈现的排序，「点过的结果之上」就无从定义。

比较改动前后可以看清操作

偏好对 = 点过的 ≻ 它上方未点击的；训练 = 调权重满足更多偏好对Algorithm 1 · PDF p.3
本课招牌演示：点击模拟结果生成偏好对，再点「训练排序函数」看权重和排序变化。默认点击第 1、3、7 位来自论文 Figure 1。试试只点第 1 位：它不产生任何偏好对。

数字需要连同口径一起读取

29 比 13 在 95% 水平显著；离线偏好错误率降到约 10%Table 2 / Figure 4 · PDF p.7
先看下方 Table 2 条形图：三组对照各赢多少次。再切换数字卡片核对每个数的口径；「Table 2 节选」里有原表数字。

点击只能给出相对偏好，不能当绝对相关性判断

点击只在浏览过的范围内构成相对比较，不能当绝对相关性判断Table 1 · PDF p.2
用 Table 1 说明平均点击位置几乎不随检索方法变化，所以点击给不了绝对分。切专业模式看三组均值和标准误。

约 260 条带点击查询训练后即胜过 Google

29:13，双尾二项符号检验在 95% 水平显著；训练只需约 260 条带点击查询Table 2 / §5.3 · PDF p.7
260 条查询就显著超过 Google，数据成本远低于人工标注。强调对照的严谨处：融合候选、盲式并排呈现、符号检验。

学到的特征权重可解释，符合该用户群体直觉

摘要匹配 +0.60 权重最高，网址长度 −0.17；权重符合该用户群体直觉Table 3 · PDF p.8
权重可解释，学生才敢信模型：科研用户组把 citeseer、Google 前 10 名给正权重，长网址给负权重。专业模式有 Table 3 节选。

点击受位置影响且有噪声，模型可能被重复点击操纵

位置偏差混进点击信号；单个用户反复点击可能操纵模型§2.2 / §6 · PDF p.3, 8
位置偏差和防作弊是论文自己承认的遗留问题，衔接下一课《点击是带偏差的隐式反馈》。可先问学生：谁能靠刷点击攻击这套系统。
