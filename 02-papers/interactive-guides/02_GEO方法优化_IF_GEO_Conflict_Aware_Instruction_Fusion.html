明确干预环节才能解释效果

指标分别回答不同的效果问题

方法的每一步都有独立作用

拖动内容预算，看各问题的满足度怎样互相挤占

预算越紧冲突越尖锐；融合把同一锚点的指令合并共享机制按附录 C · PDF p.13

单篇内容同时承接多种查询

目标查询增益 0.277，其余仅 0.087 且 69.2% 为负溢出Table 4 · PDF p.11
附录 A 的诊断实验：只优化一个查询，收益集中在它身上，其他查询平均只有它的三分之一，七成查询对出现负溢出。

指令之间可能相互竞争

三条建议指向同一定义句却互斥，必须裁决或合成附录 C · PDF p.13
冲突的样子：附录 C 里三条建议都要改首句，一个要通俗化，两个对术语的解释互相矛盾。各自合理，加起来就是冲突。

先分散再汇聚可以协调改写

去掉冲突解决，平均增益从 9.24 跌到 6.14Table 3 · PDF p.8
消融实验分出分工：冲突解决是安全阀，指令融合稳住胜平率，蓝图主要影响增益能否落地。切换三个环节看各自贡献。

稳定性评估需要关注低表现查询

WCP −0.0090、WTR 80.50%：低端损失也更小Table 2 · PDF p.7
IF-GEO 的方差反而更大（0.0189），论文提醒方差混入正向波动；判断低端要看 WCP 与 DR，IF-GEO 在这两项都是全场最优。
