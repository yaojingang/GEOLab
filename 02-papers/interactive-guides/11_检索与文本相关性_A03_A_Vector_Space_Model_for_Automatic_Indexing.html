向量空间检索模型

检索表现与空间密度成反比：好词让文档彼此远离。摘要 · PDF p.1
开场先给一句话结论：文档画成加权词向量后，检索表现与空间密度成反比，好词让文档彼此远离。提醒学生：右下角几个数字后面会逐个展开。同时带上条件——结论来自小型英文摘要集合。

沿着问题与证据完成这门课

先读结论，再拆机制、指标、证据与应用，最后带回适用条件。
过一遍四个学习问题和七章路线。告诉学生：术语都可以点开看解释，进度自动保存，随时可以按 M 切换专业层。

什么样的词最适合把不同文档区分开

大路词把页面挤成一团；中频专有词把向量夹角拉开。教学示意。
先让学生自己想：同主题页面词表几乎一样，系统靠什么挑出最相关的一篇。再切换常见做法与研究启发，对比差距。强调这是教学示意，后面会用论文实测数字收口。

研究对象需要先拆开再比较

空间密度：文档与主中心相似度之和，越小越分散。原文 §1–§2
点开三个环节卡逐一讲。重点讲空间密度：所有文档与主中心的相似度之和，越小越分散；区分值衡量一个词能把这个和改变多少。

方法沿着这些环节产生作用

表示成向量 → 用夹角相似度算距离 → 按区分值挑选标引词。
按步进器走三步：表示、度量、选词。指出论文干预的是第三步——按区分值挑词表。专业层附实验设置与证据范围。

明确干预环节才能解释效果

干预环节是标引词表；密度是观测量，检索表现是结果量。
切换三个环节，讲清这门课能支持什么结论：理论框架与受控集合实验，没有生产环境实测。让学生记住这个口径。

指标分别回答不同的效果问题

式(3)：密度用文档与主中心相似度之和近似，n 次比较即可。原文 §1 · 式(3)
两个指标各答一个问题：密度问「空间挤不挤」，区分值问「这个词能不能拉开空间」。专业层给出式(3)与式(4)的口径。

实验设置限定结论的适用范围

空气动力学 424 篇、医学 450 篇、世界事务 425 篇；结论限于英文摘要类小集合。原文 §2 · §4
三个集合的规模与来源：空气动力学 424 篇、医学 450 篇、世界事务 425 篇。右侧可切换原文摘录，让学生看到原始表述。

保持对照一致才能解释变化

复验四件事：对象一致、基线明确、版本记录、报告负向结果。
让学生给复验方案逐项打勾：对象一致、基线明确、版本记录、负向结果。四项齐了才算完整。

方法的每一步都有独立作用

三步各有独立作用：表示决定可比性，度量决定距离，选词决定区分力。
点三步，每步对应一条发现：表示方式决定可比性，相似度决定距离，选词决定区分力。约束清单提醒口径不能漂移。

比较改动前后可以看清操作

拖动向量看相似度排序与密度变化；演示数值为二维示意。
本课招牌演示。先点「操作前」：三篇页面向量挤成一团，密度接近 1。再点「操作后」：夹角拉开、密度下降、排序清晰。最后让学生自由拖动，观察只改长度时余弦值不变。

数字需要连同口径一起读取

IDF 提升约 14%、DF 正序加权损失约 10%，密度同向变化。原文 §2–§3
四个标签页切换：精度对比、密度操作、词频分布、原文 OCR。先读零线基线再读条形；所有数字标注原文出处。

检索表现与文档空间密度成反比

四组证据同向：表现更好时空间更散，空间压缩时表现下降。原文 §2–§3 · Table 1–4
先读断言，再看右侧核查路径。专业层列出四组同向数字：约 +14%、约 −10%、拉伸后密度下降、压缩后精度损失 12% 到 13%。

文档频次中等的词区分力最强

中频词区分力最强；太冷门与太常见的词都差。原文 §4 · Fig 6–7
讲反直觉处：太冷门的词同样拉不开文档。医学集里文档频率为 1 的几千个词，平均区分排名在 3000 名之后。

高频词宜组成短语低频词宜并类

高频词并成短语、低频词并成类词书，三集合整体提升 17%–50%。原文 §4 · Table 6
用 TIME 集的好词差词举例：Buddhist 是好词，Nation 是差词。两条对策：高频词组成短语，低频词并成类词书。

IDF 加权较纯词频加权提升约 14%

IDF 加权较词频加权提升约 14%（424 篇空气动力学）。原文 §2
专业层给出 IDF 公式。提醒口径：约 14% 是 424 篇空气动力学文献上十个召回点的平均精度提升。

相关研究帮助检验迁移边界

与 1988 年词加权研究对照：tf×IDF 加归一化成为通用配方。
对照仓库内 Salton 1988 词加权研究：tf×IDF 加长度归一化成为后来的通用配方。提醒两篇论文的数字口径不同，不能相加。

把方法还原为一次具体操作

论文原例：TIME 集区分值排出的好词与差词。原文 §4 · Table 5
论文原例：1963 年《时代》周刊 425 篇文章，区分值把 Buddhist、Viet 这类专有词排前面，把 Work、New 这类高频词排后面。出处 Table 5。

不同角色需要不同的执行清单

行动清单按角色拆分；建议为本课推断，需复验后采用。
切三个角色读行动清单，每条都能追溯到某条发现。提醒：建议是本课推断，使用前先做小范围复验。

成熟工作形态可以承接研究方法

用词频审计表承接区分值思路；映射关系是本课推断。
讲词频审计表怎么承接区分值思路。强调映射关系是本页推断，先小范围试再推广。

结论的边界决定应用的尺度

结论限于小集合与聚类近似；最优频段需按新语料重新估计。
逐条过六个局限，重点两条：小型集合与聚类近似；评价口径决定能推断什么。引出后续研究做对照。

带走结论时也要带走条件

带走结论，也带走边界与口径。
