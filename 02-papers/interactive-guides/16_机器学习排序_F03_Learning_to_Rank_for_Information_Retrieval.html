排序学习三类方法综述

综述把排序学习分为单文档、文档对、文档列表三类；在公开基准 LETOR 上列表法整体最好，成对法优于单文档法，多数训练损失是排序指标的上界。摘要与研究目标 · PDF p.3
开场先给一句话结论：三类方法、列表法在 LETOR 上整体最好。右侧四个数字是两个语料的规模，先建立量级感。提醒学生：结论的条件写在要点里，对比基于 2007 年的基准与当时调参水平。

三类方法的差别，从输入空间就开始了

单文档法与成对法把整组排序拆小处理，位置信息因此丢失。§1.2.3 · PDF p.18
从问题切入：为什么逐篇调分，整组排序未必变好。先让学生猜，再切到「研究启发」看综述的回答：损失要对齐查询级、位置敏感的指标。方法地图在第 10 页展开。

MAP 与 NDCG 都按查询、按位置计分

顶部折扣最小：第 1 位为 1，第 5 位约 0.39。§1.1.2 · PDF p.12
指标页对比 MAP 与 NDCG：都是查询级、按位置计分，这正是三类损失要对齐的对象。专业层给出 DCG 公式：增益 2^l−1，折扣 1/log₂(r+1)。让学生说说顶部位置为什么更值钱。

七个数据集上统一评测七种代表算法

LETOR 基准：Gov 与 OHSUMED 两个语料、七个数据集、五折交叉验证，比较七种代表性算法。§6.1–6.2 · PDF p.66
实验设计页讲 LETOR：Gov 与 OHSUMED 两个语料、七个数据集、五折交叉验证。所有算法都用 MAP 在验证集上选模型，这是公平比较的关键。右侧可切换查看原文抽取。

输入空间决定损失，损失决定位置敏感度

输入空间决定损失形式，损失决定位置信息能否进入训练。§1.2.3 · PDF p.18

顶部一对判反，代价大过底部错排

同一份标注三种拆法，NDCG 差距由位置折扣实算得出。式 1.8–1.9 · PDF p.12

五个指标列上列表法都高过成对法基线

MAP 列：ListNet 33、AdaRank 27、RankSVM 24、线性回归 4。Table 6.12 · PDF p.75
证据读数页：获胜数条形图，可切五个指标列。让学生读出 ListNet 在每列都高过成对法基线，P@10 列 AdaRank 与 SVMmap 是例外。下方可切数据集规模卡与原文表格节选。

单文档法与成对法都看不到结果列表中的位置

位置与查询级信息缺失，损失与评估指标脱节。§1.2.3 · PDF p.18
发现 1：两类损失看不到位置与查询级信息。切「实践含义」看这带来什么，切「适用条件」看边界。右侧给出核查路径，可跳回原文证据。

列表法直接面向查询级与位置敏感的评估指标

两条路线：近似或上界指标、最小化列表损失。§4 · PDF p.45
发现 2：列表法把位置带进训练。代表算法分两条路线：SoftRank、AdaRank、SVMmap 直接优化指标；ListNet、ListMLE 最小化列表损失。代价是训练复杂度，专业层有细节。

LETOR 基准上列表法整体表现最好

MAP 获胜数：ListNet 33、AdaRank 27、RankSVM 24、线性回归 4。Table 6.12 · PDF p.75

多数方法的训练损失都是排序评估指标的上界

成对损失经 essential loss 成为 (1−NDCG) 的上界。§5.2 · PDF p.59
发现 4：损失与指标的上界关系。成对损失先上界 essential loss，后者再上界 1−NDCG；单文档上界在例题里约 1.15，大于 1 就失去意义。专业层有完整链条。
