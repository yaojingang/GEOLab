# opt-83 科学引文索引构想

- 文件：`13_链接分析与外链理论_C01_Citation_Indexes_for_Science_A_New_Dimension_in_Documentation_through_Association_of_Ideas.html`（98,624 bytes，≤ 200 KB）
- 论文：Garfield, *Citation Indexes for Science*, Science 122(3159), 1955（年份按 1955 Science 原文；1964 年 SCI 创刊仅作边界说明保留）

## 审计发现（优化前）

1. 全课为通用模板内容：概念/流程/实验室/指标等页只重复 `PAPER.steps` 与模板句，几乎看不到论文本身。
2. 无招牌交互；第 4 页（核心概念）大片留白，只有三步按钮加一段复述。
3. 证据读数页只有"单个大数字 + 上下文"，23 与 500 这对最关键的数字没有对比图。
4. 案例页缺 `originalCases[83]`：论文明明有真实原例（Selye 1946，5 年 500 余篇核对出 23 篇引用），页面却显示 GEO 教学示意。
5. 自测五题是模板腔（"保证所有引擎采用同一套来源"等干扰项与本文无关），解释无复习页码细节。
6. 讲稿全部是同一句模板（"这一页围绕…展开。请先观察默认状态…"）。
7. 专业层几乎没有论文内容：编码结构 11123a-687、R/A/O 文献类型、规模估算（100,000 × 10 ≈ 100 万）、Shepard's 对照（30,000 判例 / 年增约 100 万条 / 每判例近 40 条）都没出现。
8. `PAPER.evidence` 是 PDF 乱码 OCR（脊髓灰质炎参考文献表），完全不可读。

## 已做优化

1. **招牌交互「引文追踪台」x-cnet（第 4 页）**：向前/向后双向追踪。
   - 向前：以 Selye 1946（索引码 11123a-687）为起点，按 1947–1951 五批「追下一批」，逐批追出论文 Table 1 的全部 23 篇真实引用来源（作者、年份、中文转述主题），实时显示 23/23 进度；追满后揭示论文反常发现——23 篇全被 Quarterly Cumulative Index Medicus 收录却无一篇归入「Adaptation」标题（PDF p.3）。
   - 向后：从 Andrew 1953 信息论文章出发，点「翻到正文最后一段」追出藏在末段的 RCA 盲人阅读机引用（Zworykin & Flory 1947），对应原文跨领域引用论证。
   - 方向切换复用 `.choice-row`（方向键已 preventDefault，不会翻页）；动态区 `aria-live="polite"`；按钮一律 `<button>`；专业层补 Table 1 样例条目结构（被引码 + 来源码 + R/A/O）。
2. **证据读数页升级（第 12 页）**：四个视图——「Selye 样例」带口径横条图（500 余篇核查 vs 23 篇被引，按 23÷500≈4.6% 换算并注明）；「科学文献规模」「Shepard's 判例对照」大数字卡 + 口径解释；「原文表格节选」用 `PAPER.table`（Table 1 假想索引条目，含 R/A/O 图例，注明扫描件 a/s 难辨以原文为准）。
3. **案例页接入论文原例**：`originalCases[83]` 写入 Selye 样例（查询、范围、核对流程、出处 Table 1 · PDF p.3–4），不再显示教学示意。
4. **改动实验室重做（第 11 页）**：主题索引路径（检索 Adaptation → 命中 0 篇）vs 引文索引路径（被引码 11123a-687 → 命中 23 篇），mock 检索界面标注示意，结论转述自原文；差异落在「组织方式」而非覆盖。
5. **自测五题全部重写**：核心结论、反常发现（Adaptation 标题 0 篇）、指标理解（impact factor vs 发文数量）、适用边界（覆盖有限与跨领域引用）、局限（泛引需逐篇甄别）；干扰项貌似合理，解释附复习页码。
6. **发现页 4 条 details 扩写**（各约 80–90 字），补机制与证据（志愿标引队伍、Lehman/Dennis 发文数量对照、逐篇核对性质、确证证据）；每条发现的出处改为对应原文段（开篇主张/引用即标引/影响因子/引用性质核查）。
7. **PAPER 数据重建**：`evidence` 换成 7 段干净原文节选（开篇主张、引用即标引、影响因子、引用性质核查、Selye 样例、主题索引漏项、规模与 Shepard 对照，均带 PDF 页码）；`stats` 从 4 条扩到 10 条（30,000 判例、每判例约 40 条、1–3 million 年新增文章、100,000 条 Current List、10 条平均参考文献、50 million+ 累计）；新增 `citers`（23 篇真实引用来源）与 `table`。
8. **专业层加深**：指标页补论文原话（impact factor 定义句）与规模估算算术；流程页补索引码示例与卡片三要素；概念页补 Table 1 条目结构；数字页补样例口径。
9. **23 页标题/要点/讲稿全部重写**：标题改断言句（如「主题标题 0 命中，被引起点 23 篇」「向前追被引，向后追出处：引用链两头都能走」）；本页要点与出处逐页对应；讲稿改为每页 2–3 句的具体教学提示。
10. **角色清单与成熟形态页重做**：三类角色各配被引记录相关行动项；成熟形态映射为「数据库被引列表 / 选源核查单 / 综述引用甄别」（保留"本页推断"声明）。
11. 文案巡检：全文无「不是…而是」类句式、无禁用词、无 emoji（仅保留外壳 ☰ 与勾选 ✓）；数字与中文间半角空格；新增 CSS/JS 一律 `x-` 前缀（x-cnet/x-node/x-chip/x-bar/x-mock）。
