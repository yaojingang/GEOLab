## 审计发现

1. 封面右侧是空壳「证据类型」卡（写着"本篇未在封面展示未经逐项核对的效果数值"），而论文有大量可核对的实测数字（Table 1、Figure 4–6、§5.3–5.4），封面关键数字位被浪费。
2. 证据读数页（p12）完全没有数字：`PAPER.stats` 为空，回退成口号 + 摘要英文节选，无条形图、无大数字卡、无口径解释。
3. 改动实验室（p11）是通用「操作前/操作后」两块面板，与论文核心机制（注入 → 选择偏移）无对应，全课无论文专属交互。
4. 案例页（p18）缺论文原例：`originalCases` 无 id 31，只有通用 before/after；论文有 Table 1 相机实验这一现成案例。
5. 自测五题为模板腔（题干/选项直接复述 PAPER.claim/boundary，出现"作者是否知名"级干扰项）。
6. 专业层无实质内容：only-pro 只重复通俗文本 + PAPER.extra；论文的正则评估口径、Table 1 派生、防御讨论均可上专业层。
7. 讲稿全为模板句（"这一页围绕…展开。请先观察默认状态…"）；多条 `.b-key` 出处统一挂"摘要与研究目标 · PDF p.1"，与页面内容不对应。
8. 发现页共用 evidence[0] 作证据出处，四条发现的实际证据位置（Figure 1 / Table 1 / Figure 5 / §5.1–5.4）未区分。
