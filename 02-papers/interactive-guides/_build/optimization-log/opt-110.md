2. 无招牌交互：p10「方法拆解」只是三步按钮复述 PAPER.steps，与综述的「三类方法地图」定位不符。
3. 发现 3（LETOR 上列表法最好）没有任何数据可视化，论文最有说服力的 Table 6.5–6.12 完全缺席。
4. p11「改动实验室」只有前后两句话对比，无可操作对象；p18 案例页为模板占位文案。
5. PAPER.quiz 五题全是模板腔（「哪项最准确概括本篇的核心贡献？」配三个无意义干扰项）。

7. PAPER.stats 的 PDF 页码全部误标为 p.3（实际 Gov/OHSUMED 在 p.66–68）；findings 无逐条证据出处。
8. 通用模板遗留死代码（originalCases、researchOnly、labHtml）。

## 已做优化

1. **招牌交互「三类方法地图」（p10 方法拆解，重写）**：三个家族按钮（单文档/文档对/文档列表，aria-pressed）→ 每类的输入输出空间、损失定义、「看不到什么」、代表算法 chips（点开看机制与章节出处：线性回归/McRank/PRanking；RankNet/Ranking SVM/RankBoost/FRank；ListNet/ListMLE/AdaRank/SVMmap）→ 底部常驻「MAP 获胜数」三色条形（线性回归 4、RankSVM 24、ListNet 33 / 满分 42，Table 6.12 · PDF p.75）。专业层含各类损失公式与上界链条。
2. **排序实验室（p11，重写）**：同一份标注（D1–D5 相关度 2/1/1/0/0，示意），切三种方法看不同预测列表（每行显示增益与位置折扣），NDCG@1 / NDCG@5 按论文公式（式 1.8–1.9）实算：单文档 0.33/0.76、成对 1.00/0.95、列表 1.00/1.00；示意标注完整。
3. **证据读数页（p12，升级 numbersHtml）**：新增「获胜数」横条图——7 算法按三家族着色、可切 MAP/NDCG@1/NDCG@3/P@1/P@10 五列、虚线基线「成对法最佳」只标首行、附 P@10 例外说明；右侧保留数据集规模卡（页码已修正为 PDF p.66–68）与原文表格节选。
4. **自测页（p23）**：五题全部重写为论文专属——分类依据（四要素）、MAP 获胜数最高者（ListNet 33）、损失与 NDCG 脱节原因、边界迁移（2007 年 LETOR）、上界关系（essential loss 链）；干扰项貌似合理，解释含复习页码。
