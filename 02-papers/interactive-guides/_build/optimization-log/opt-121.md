## 审计发现（优化前）

1. 第 11 页「改动实验室」与第 3 页「问题场景」都是两块文本的弱切换，页面大片空白，没有论文专属的可探索交互。
2. 第 12 页证据读数只有大数字卡；Table 2 五个数据集 × 两方法的可比召回率没有画成带对照系列的条形图，专业层没有完整表格。
3. 自测五题为模板腔：干扰项与论文无关（如「保证所有引擎采用同一套来源」），第 1 题正确选项直接照抄 claim 全文。
4. 全部 23 页讲稿是同一句模板（「这一页围绕…展开。请先观察默认状态…」）且以「。。」结尾；多页 b-key 与标题重复或与其他页雷同。
5. 案例页没有论文原例（originalCases 无 121）：论文附录 C Table 7 的「英格兰—爱尔兰海」例子与引言 bad guy ↔ villain 例子均未使用。
6. 专业层几乎没有公式：内积相似度（Eq. 1）、批内负例损失（Eq. 2）、Table 3 难负例消融全部缺失；四条发现共用同一个出处标签（摘要与研究目标 · PDF p.1），粒度不足。
7. 页面标题多为通用句（「方法的每一步都有独立作用」「比较改动前后可以看清操作」），未断言 DPR 内容。
8. 术语表只有两个指标词条，双编码器、批内负例、难负例、MIPS 等核心概念无解释。

## 已做优化

1. **招牌交互（第 11 页）**：新增「检索对照台」——同一问题分别喂给 BM25（稀疏关键词）与 DPR（稠密向量），三个问题各配 3 段候选、双列排名、命中理由与「含答案」标记：
   - 例 1《指环王里的反派是谁？》取自论文引言（bad guy ↔ villain，PDF p.1）；
   - 例 2《英格兰与爱尔兰之间的水体是什么？》取自附录 C Table 7（BM25 第一位为 British Cycling，DPR 第一位为 Irish Sea，PDF p.13）；
   - 例 3 为按 SQuAD 反向结论构造的高词汇重叠示意（BM25 主场）。
   - 每个问题底部给论文实测锚点（NQ Top-20 78.4 对 59.1 / SQuAD 63.2 对 68.8，Table 2），排序标注「示意」，支持 BM25 视角 / DPR 视角 / 并排对比三种视图与键盘方向键。
2. **证据读数页（第 12 页）重建**：五个可切换视图——Top-20 召回、Top-100 召回、端到端 EM（均为 BM25 灰条对照 + DPR 蓝条 + 绝对差值标签的横条图，数据来自 Table 2/Table 4）、运行效率（995.0 对 23.7 问/秒；编码 8.8 时 / FAISS 8.5 时 / 倒排 0.5 时的横条）、完整 Table 2 表格（含单集/多集、BM25+DPR λ=1.1 全行）。
3. **案例页（第 18 页）**：写入论文原例——例 1 Appendix C Table 7（BM25 捞到 British Cycling、DPR 捞到 Irish Sea），例 2 引言 bad guy ↔ villain；callout 连接 F1 与 SQuAD 反向口径，注明「未补造收益数字」。
4. **自测页**：重写五题为论文专属——核心结论数字配对（Q1）、SQuAD 反常原因（Q2）、Top-k 口径读法（Q3）、批内负例 + 难负例配方（Q4）、索引成本边界（Q5）；干扰项为貌似合理的数字组合（如对 ORQA 的 20.2、ICT 预训练），每题解释附出处与复习页码。
5. **发现页四条**：每条独立出处（F1 Table 2 / F2 Figure 1 / F3 Table 3 / F4 §5.1·§5.4），观察对象逐条定制（训练对曲线、负例类型、查询类型等）；专业层分别补 Table 2 五集全行、跨数据集迁移损失（69.9/86.3 对 75.0/89.1）、Eq. 2 损失与批内 B² = 16,384 对推导、SQuAD 反向两原因与效率对。
6. **指标页（第 7 页）专业层**：补 Top-k 准确率定义式与 sim(q,p) = E_Q(q)ᵀ·E_P(p)（Eq. 1），注明 d = 768、k 取 20/100、BM25 参数 b = 0.4、k1 = 0.9。
7. **其他页面深化**：系统流程页专业层补 21,015,324 段、[CLS] d=768、FAISS HNSW；方法拆解页步骤-发现对应（XMCALL）；批判阅读页六条局限按新证据重写（SQuAD 反向、索引成本、更复杂未必更好、正例来源受限、ColBERT 对照、版本口径）；角色清单、成熟形态对照改为 DPR 专属内容；研究对照页补 §7 后续路线（与 BART/T5 结合、RAG 课 id 50-52 呼应）。
8. **文案与讲稿**：23 页讲稿全部重写为逐页具体内容（含「。。」修复）；12 个页面标题改为断言句（如「双塔各编各的向量，相遇只算一次内积」「四个数据集大幅领先，SQuAD 反向」「ColBERT 用晚期交互回应检索代价」）；全部 b-key 补论文数字与出处；术语表新增双编码器、批内负例、难负例、MIPS 四个词条并接入术语浮层。
9. **无障碍**：新增控件全部为 `<button>` + `aria-pressed` 分组，动态区 `aria-live="polite"`，方向键沿用 preventDefault 处理；新增 CSS 类一律 `x-` 前缀。
