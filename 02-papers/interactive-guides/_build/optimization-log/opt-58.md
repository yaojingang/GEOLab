# opt-58 主张门控的信源审计

## 审计发现（优化前）

1. 全课只有通用选项按钮模板，没有任何论文专属交互；论文最核心的机制——四项三态判据（I/A/M/D）门控合成端点、缺证保持未决——完全没有可操作的演示。
2. 证据读数页（p12）只有一张大数字卡「81」加一行口径，留白严重；论文最有教学价值的表 II（七种规则在 81 个状态上的契约对照）与表 III（八组一致性检查）完全未用。
3. 指标页（p7）专业层只重复通俗文本，没有公式：论文的完整案例端点（式 1）、五维证据向量（式 2）、审阅优先级（式 3）全部缺席。
4. 自测五题为模板题（选项如「用页面总分直接替代业务结果」与本论文无关），正确答案直接复述 claim，解释无出处。
5. finding_details 每条仅 24–31 字；发现页出处一律标注「摘要与研究目标 · PDF p.1」。
6. 23 页讲稿全部是同一句模板（「这一页围绕……展开。请先观察默认状态……」）；23 页「本页要点」出处几乎全部错标为 PDF p.1。
7. 拼接语病：流程页/方法页出现「……什么关系？。」双重标点；角色页「避免：有引用角标就默认来源独立后，直接宣称……」语法不通。
8. 案例页虽有原例框架但只有两句抽象转述，无具体查询、来源、答案与判据落位。

## 已做优化

1. **招牌交互「门控审计台」（p11 改动实验室）**：四项判据（关系证据 I / 答案采用 A / 重要性 M / 披露充分 D）各可切「真 / 假 / 未决」三态，右侧实时给出端点结论——任一判据为未决即显示「未决 · 保持未决」（橙色）；四项齐备且 I∧A∧M∧¬D 显示「已证实遗漏」（红色）；否则「无遗漏」（绿色），并解释由哪条判据否定。5 个预设场景取自论文：付费关联评测 (1,1,1,0)→遗漏、公司自述规格 (1,1,1,M=0,D=1)→无遗漏、未采用来源主张 (1,0,1,0)→无遗漏（对应论文 drop-A 消融示例）、规定检索未见关系 (0,1,1,1)→无遗漏并提示「不等于来源独立已证实」；默认态 (1,1,1,U) 直接演示「缺证保持未决」。另有「引文支持」有/无开关——切换不改变结论，用于演示支持分离不变量。规则脚注给出口诀，专业层补式 1 与短路政策覆盖代价（66/81 vs 16/81，§IV-C · PDF p.4）。全部 `<button>` + aria-pressed，动态区 aria-live="polite"，判据三态组复用 .choice-row 使方向键在组内切换（沿用课程已有 preventDefault 处理）。
2. **证据读数页（p12）重写**：四个视图——「基线对照 · 表 II」按越权结论 F / 保持未决 U / 已决不一致 E 三个维度切换，7 条规则画成自 0 起算的横条图（基线行「完整案例参考」加粗，理想读数标注，满格=65 个状态）；「检查清单 · 表 III」八组检查通过/测试数紧凑表；「计算成本 · 微基准」两张大数字卡（0.49 µs/元组、51.20 µs/记录，§IV-E 口径）；保留「原文表格节选」核验入口。每处标注「规范计数，不是检测错误率」（表 II 原注）。
3. **案例页（p18）升级**：论文引言原例逐判据落位——三元组芯片（查询 q / 来源 u / 答案 a）、判据 1 关系 I=1、判据 2 采用与重要性 A=1、M=1、判据 3 披露 D=0→遗漏，另加对照组「公司自述规格不是遗漏」，收尾点出支持分离不变量；标注答案文案为教学转述。
4. **自测五题重写**：核心结论（(1,1,1,0) vs (1,1,1,1)，复习 p7）、缺证机制（D=U 保持未决，p11）、指标口径（guarded support-only 1/16 的幸存者偏差，p12）、设计取舍（短路政策 66/81 覆盖代价，p15）、局限（表 IV 五扇验证门只完成有限契约一致，p21）；干扰项貌似合理，每题解释含出处与复习页码。
5. **发现四条扩写至 55–75 字**并补机制/证据；发现页每条新增专业层注记（引言示例、表 I「关系不意味着欺骗」、(0,1,1,U) 文档要求与移除证据不变量、表 III 与图 2 序列），出处逐条改为 引言 p.1 / 表 I 注 p.3 / §III-A p.2 / §IV p.4。
6. **专业层加深**：指标页补端点公式 R_O(r)=U，若 I、A、M、D 任一为 U；否则 I∧A∧M∧¬D、三态卡（U 不是假）、覆盖代价（§IV-C）；记录合规补记录契约要点（SHA-256 快照摘要、缺键/U/0 不互换，§III-E · PDF p.3）；流程页补六步执行次序（§III-C · PDF p.2）；方法页补表 I 来源角色关键行列（PDF p.3）；实验设计页补「无训练、无真实数据集、无网络访问」（§IV-A · PDF p.3）；批判阅读页补表 IV 主张门全景与可推翻规范的结果清单（§V-C · PDF p.5）。

8. 对照检查页（p9）四个复验条目改为论文专属（证据区间、支持分离、版本绑定、未决如实报告）；角色行动页（p19）同步新 steps/after；成熟形态页保留风险研究必需的 .callout.warn 底线提示并细化中间列字段。
