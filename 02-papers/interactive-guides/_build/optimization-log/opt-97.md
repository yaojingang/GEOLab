1. **招牌交互（p11 改动实验室）**：新增「支持者分布体检」（x-hist 组件）——按论文 Algorithm 4 的桶规则（a=0.1、b=0.7，桶号越大 PageRank 越低）把约 1000 个支持者的 PageRank 直方图画成对数刻度柱状图，叠加幂律拟合的期望虚线；拖动「刷分支持者占比」滑杆（0–100%，原生 range + aria-label），实时计算 ρ = Pearson(桶号, log 桶量) 并与论文阈值 ρ0=0.85 比较：默认诚实形态 ρ=1.00「未触发罚分」，占比约 55% 起跌破阈值，90% 时 ρ=0.72、罚分 (ρ0−ρ)=0.13，100% 时只剩 1 个非空桶、ρ 按 0 处理（忠实于 Algorithm 4 只取非空桶的口径）；判定翻转时提示按 (ρ0−ρ) 记罚分并衔接第三阶段 PPR(Penalty)。三个预设按钮：诚实页对照 / 混入 30%（ρ=0.93，未触发）/ 论文警惕形态 90%（红色窄区间桶 + 记罚分）。直方图标注「示意数据」，桶规则、阈值、罚分公式、变体 II 均带 Algorithm 3/4 · PDF p.7 出处；专业层补 ρ 公式与幂律理论桶量 ∝ b^(−(α+1)k) 推导。控件全部 `<button>`/原生 range，动态区 aria-live="polite"，预设行支持方向键（preventDefault）。
