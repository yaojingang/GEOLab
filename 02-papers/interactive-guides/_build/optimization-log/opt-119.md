## 已做优化

1. **招牌交互（p11 改动实验室）**：按论文机制新造「匹配直方图 + 门控消融」实验室——左侧用论文 §4 原例（查询词 car 对 6 个文档词的余弦相似度）实时绘制 5 桶直方图；右侧两个论文依据的开关：
   - 「词项门控（IDF 加权）」关 → 改均匀求和，读数区出现 Robust04 MAP 0.279→≈0.260、ClueWeb 0.113→≈0.109 的对照条（虚线为 BM25 基线 0.255/0.101），注明相对下降 6.8%/3.5% 与换算方式（§5.5.1）；
   - 「精确匹配单列一桶」关 → 直方图精确桶并入 0.5~1（[0,1,3,1,1]→[0,1,3,2,0]），注明论文未单测该开关，旁证为 MP_DOT 0.083 vs MP_COS 0.189（Table 2）；
   - 默认态给出 +9.4%（本课换算）/ +11.9%（§5.4）与动态池化显著更差（Figure 3）的提示。开关为 `<button aria-pressed>`，读数区 `aria-live="polite"`，方向键复用既有 preventDefault 处理。
2. **证据读数页（p12）重写**：4 个视图全部带基线与数据标签的 HTML/CSS 条形图——①两基准模型对比（Robust04 六条 / ClueWeb 五条，虚线 BM25 基线）；②对 BM25 相对提升 MAP +11.9% / nDCG@20 +14.7% / P@20 +12%（§5.4）；③消融读数（−6.8%/−3.5% 及换算后 MAP）；④Table 2 节选表格（7 行，主题标题 MAP）。每个数字带出处。
3. **案例页（p18）**：`originalCases` 新增 id 119 条目，使用论文原例（car 直方图）中文转述，出处「§4 匹配直方图示例 · PDF p.5」，不为案例补造提升幅度。
4. **自测 5 题重写**：覆盖核心结论（三要素）、反常发现（DSSM 0.095 vs QL 0.253）、指标理解（11.9% 的确切口径，含 nDCG/P@20 干扰项）、适用边界（重排口径）、消融结果（去门控 6.8%/3.5%）；干扰项貌似合理（如 14.7% 换指标、端到端全库、损失不收敛），每题解释含数字与复习页码。
5. **发现页扩写与出处修正**：4 条 finding_details 补齐证据数字（MP_DOT 0.083 vs MP_IND 0.169；门控 300 参数 vs 匹配网络 155 参数；动态池化/K-max 结论），每页出处改为 Table 2/§5.4/Figure 3 实际位置。
6. **23 页讲稿全部重写**为教师口吻（2–4 句，指明动什么、记什么），本页要点全部改为信息量断言并挂正确出处；修复全部「。。」与「？。」连用（含 notesForStep 模板）。
