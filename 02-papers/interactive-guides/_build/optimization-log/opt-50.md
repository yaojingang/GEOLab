## 审计发现（优化前）

1. 指标口径错误：IE 被写成"相关证据相对于消耗上下文的效率"，论文定义为 IE@k = Precision@k × Recall@k（k∈{1,3,5} 平均、三次运行，§4.1 · PDF p.6）；指标页、术语表、自测全部沿用错误口径。
2. 证据读数页（p12）只有一个大数字加两块留白，无条形图、无基线；PAPER.stats 仅 2 个数字。
3. 改动实验室（p11）只是"操作前/后"两段文本卡，无机制演示；全课无论文专属的可探索交互。
4. 案例页（p18）无论文原例（originalCases 缺 id 50），回退到模板示意；而论文 Appendix G 有两个现成定性案例（Figure 4 LegalBench-RAG、G.2 Dragonball）。
5. 自测五题为模板题，干扰项与论文无关（如"网页颜色是否好看""作者是否知名"）。
6. 全部 23 页讲稿为同一句模板（"这一页围绕…请先观察默认状态…"）；本页要点出处一律"摘要与研究目标 · PDF p.1"；发现 2/3/4 的要点与标题逐字重复。
7. finding_details 每条仅 24–31 字，无机制与证据；专业层几乎无公式与表格（论文有 IE 定义、BCE+KD 损失、Table 1-5 关键数值、K/L/M/k 超参）。
8. 论文内部不一致未披露：摘要 +8.24% 换算口径未给；Table 10 列头（Recall/Precision/IE）与 Table 1（IE/Precision/Recall）对同一数值三元组标注相反；"over 10× fewer tokens"实算 41,058/4,126≈9.95×。

## 已做优化

1. **招牌交互「有无主题向量指引的检索对比」（p11 改动实验室）**：按论文 Figure 4（PDF p.22）原例重演——LegalBench-RAG 中"Superior Proposal"定义检索，5 个候选条款（C1-C5）各自带条形与分数；开关切换「改动前 · 仅余弦相似度」（C2 0.81 错排第 1、金块 C3 0.78 排第 2）与「改动后 · 加主题向量」（MLP 重打分 C3 0.89 ✓ 取回、C2 0.57 降位），并显示选择器激活 T-A/T-B、抑制 T-C/T-D 的主题信号面板；红/绿判定条与图注标明两种分数来自不同打分器。全部 `<button>` + aria-pressed + aria-live，方向键组内切换（preventDefault），分数全部为论文报告值。
2. **证据读数页（p12）重写**为四个标签：六基准 IE 对照图（蓝条 MCompassRAG / 橙条基线 SAKI-RAG 成对横条，右列数值 + 按表换算的相对提升，图注披露与摘要 8.24% 的口径差异）；时延与上下文（10 方法线性条形，本方法 174 ms · 4,126 tok 高亮）；摘要口径卡（+8.24% 与 >5× 两张大数字卡配口径解释）；Table 1 节选（仅 IE 列，注明删减）。封面同步扩为 4 张数字卡（补 174 ms、4,126 tok，出处 Table 2）。
3. **案例页（p18）升级为论文原例**：originalCases 新增 id 50——Figure 4 的查询、dense 错排（0.81/0.78）、主题修复（0.89/0.57）中文转述，外加 G.2 Dragonball 财报嵌入空间例子；图注写明分数为论文报告值、未补造收益。
4. **自测五题重写**：核心结论（方法三部曲）、反常发现（主题信号非越多越好：Figure 3 的 12-15 峰值与 Table 10 的 K=100 最优）、指标理解（IE@k=P×R）、适用边界（多轮固定预算的深度研究场景）、论文自述局限（主题模型质量依赖）；干扰项貌似合理，每题解释含复习页码。
5. **发现四条扩写至 55-80 字**，逐条配证据（Table 2、Figure 4、Table 1、§4.2 神谕差距 0.54/0.30 点）；发现页证据出处改为逐条对应（evMap），新增"实践含义/适用条件"论文专属内容与"看同口径数字"跳转。
6. **专业层加深**：指标页补 IE 公式（分因子解读）与训练目标 L=(1−α)·L_BCE+α·L_KD（α=0.5、τ=1.0，式 11-13）；方法页补关键超参 K=100、L=50、M=10 与 20,000 合成对（§3.3、Appendix C）；新增术语：主题模型、主题质心、知识蒸馏、难负例、神谕上界。
7. **批判阅读页扩为 7 条**：主题模型质量（含 Table 11 缓解证据 38.97→39.26）、超参敏感（Figure 3/Table 10 数值）、有损压缩、评估口径限定迁移、内部不一致（8.24% 换算、9.95×、Table 10 列头矛盾，注明"以表格数值为准"）、SproutRAG 仓库内对照（带链接）、单一实现栈（Table 4/5）。
8. **文案与讲稿巡检**：23 页讲稿逐页重写（2-4 句口语化）；23 页页面标题改为论文专属断言句（连读可复述论文）；本页要点逐页改写并配精确出处（Table 1/2、Figure 3/4、§3-§4、Limitations 等）；steps/before/after/query 更新为论文机制表述；金句页 6 卡重写为论文专属（正面口诀 + 背面依据/用法）；无"不是…而是"句式、无禁用词、无 emoji（保留外壳 ☰ 与既有 ✓ 勾选符），数字与中文间加半角空格。
9. 角色行动页重写为三类角色（RAG 工程师/平台架构/知识库运营）各 4 条可追溯清单；成熟形态页重写为三张台账（检索基准卡/主题元数据台账/时延与 token 预算表）；研究对照页"对照启发"改写为两篇干预环节差异的具体说明。
